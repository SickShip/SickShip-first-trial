# SickShip-first-trial

第一个 Git 练习项目。

## 开始使用

```bash
# 克隆仓库
git clone https://github.com/SickShip/SickShip-first-trial.git

# 进入目录
cd SickShip-first-trial
```

## 常用命令

```bash
git status              # 查看改动状态
git add .               # 暂存所有改动
git commit -m "说明"    # 提交
git push                # 推送到远端
```
